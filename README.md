# Patrick Leegte

**Van de werkvloer tot de AI-laag.**

Ik begon als draaier en lasser. Via technische verkoop, werkvoorbereiding en ERP-implementaties groeide ik door naar technical manager en projectleider. Vandaag help ik bedrijven hun werk slimmer en efficiënter te organiseren, op locatie of op afstand. Ik bouw en beheer ERP-systemen waarin AI is ingebouwd, en maak tools en webshops voor technische bedrijven.

Ruim twintig jaar maakindustrie, maritiem en zware industrie.

## Wat ik nu doe

- **Optimaliseren**: bedrijfsprocessen en systemen, op locatie of op afstand.
- **Bouwen en beheren**: ERP-systemen met AI ingebouwd, die leeswerk overnemen: offertes, werkorders, facturen.
- **Maken**: tools en webshops voor technische bedrijven.

## Waar ik mee werk

Laravel en PHP, PostgreSQL, Vue, Python, Docker en Traefik op eigen servers in Nederland. AI ingebouwd in bedrijfssystemen: documenten lezen, tickets voorbereiden, bestellingen klaarzetten. Een mens controleert en beslist.

## Hoe ik werk

1. **Eerst kijken, dan bouwen.** Het probleem zit zelden in de techniek, meestal in de systemen eromheen.
2. **Demo voor het akkoord.** Elk onderdeel komt eerst in een testomgeving.
3. **Mens beslist, software bereidt voor.**

De code die ik voor klanten bouw staat in besloten repositories.
